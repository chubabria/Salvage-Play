## 🎮 რა თამაშია

შენ დგახარ შენი მიწისქვეშ ჩამარხული ხომალდის ტრიუმში, გალაქტიკის მიყრუებულ პლანეტაზე, სადაც **გაჭედილი ხარ საწვავის გარეშე.**
ყიდულობ ჯართს უცნობებისგან, ცდილობ გაარკვიო რომელი მათგანი გატყუებს და აგროვებ იმ თანხას, რომელიც პლანეტიდან გაგიყვანს, სანამ რადიაცია კორპუსს დაშლის.

შენ **ექსპერტი ხარ, არა მებრძოლი.** სიამოვნება იქიდან მოდის, რომ *მიხვდი*. სპექტრომეტრმა თქვა ირიდიუმი, სასწორმა თქვა, რომ სიმკვრივე არ ჯდება, და შენ ახლა იცი ის, რაც იმ კაცს ეგონა, რომ არ გეცოდინებოდა.

### როგორ მიდის თამაში
- **დღე:** ზედაპირზე ქარბუქი ძლიერდება (სიმშვიდე → ქარბუქი → პიკი → კრიტიკული). მოხეტიალეები მოაქვთ ნივთები. ამოწმებ ხელსაწყოებით, ვაჭრობ, ყიდულობ.
- **ღამე:** ნაპოვნს ყიდი ფრაქციებზე, ყიდულობ აღჭურვილობას, იგერიებ რეიდებს.
- **რადიაცია ორ რამეს აკეთებს:** კორპუსს ცვეთს, მაგრამ რაც უფრო მაღალია, მით უკეთესი ნივთები შემოდის. **საუკეთესო გარიგებები ყველაზე ცუდ მომენტშია.**
- **მიზანი:** იყიდე საწვავი (1 000 000) და გაფრინდი. ან კორპუსი 0%-მდე ჩამოვა და გავლა მთავრდება.

ერთი გავლა დაახლოებით 20–30 თამაშის დღეა.
